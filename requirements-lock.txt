# Regenerate after any dependency change:
#   pip install -e ".[dev,gpu]"
#   pip freeze | findstr /v "^-e " > requirements-lock.txt   # Windows
#   pip freeze | grep -v "^-e " > requirements-lock.txt        # Linux/macOS
#
# To reproduce this exact environment (plus the local editable install):
#   pip install -r requirements-lock.txt
#   pip install -e ".[dev,gpu]"
#
# The torch/torchvision pins below carry a +cu130 local version and are
# therefore MACHINE SPECIFIC: they resolve only from the CUDA 13 PyTorch
# index and only run on a driver that serves CUDA 13.x (580+). On a host
# with an older driver, install the torch pair for that driver's CUDA
# version first (see README, "Prerequisites"), then install the rest of
# this file -- everything else here is CUDA-agnostic:
#   pip install -r requirements-lock.txt --no-deps  # or drop the two torch lines
# A mismatched wheel does not degrade to CPU; it fails every allocation
# with cudaErrorDevicesUnavailable.
