VISTLabel Help

VISTLabel annotates videos frame by frame: you segment objects with SAM prompts and the brush, propagate them through the video, review the result and export a YOLO or COCO dataset.

New here? Start with the user guide, which walks through a project from upload to export. Everything here is served from the local docs/ directory, so no network access is needed.
