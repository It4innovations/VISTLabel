Account setup required

VISTLabel has exactly one user account and it has not been created yet. The account is created on the server, never through the browser. Run, inside the application's virtual environment: 

vistlabel auth set-password --username <name>

The command prompts for the password (or reads VISTLABEL_PASSWORD from the environment) and stores only an Argon2id hash under the workspace. Then continue to sign in.
